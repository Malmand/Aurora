# Basemap

`luzon_strait_land.geojson`: Natural Earth 1:10m land and minor islands (public domain, naturalearthdata.com, via github.com/nvkelso/natural-earth-vector), merged, clipped to 113 to 131 E and 10.5 to 27.5 N, simplified by 0.003 degrees. Used only for the map in `figures/final/figa_site_system`.

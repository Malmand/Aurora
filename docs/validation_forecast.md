# Forecast validation: Itbayat solar and demand

Generated by `python -m aurora.forecast.build` on 2026-11-02. Reads only `data/itbayat/raw_small/` and the Phase 1 outputs.

## Verdict

- Evaluation: rolling-origin backtest, monthly refit, 24 test months (Nov 2024 to Oct 2026), daylight hours, satellite reference.
- **AURORA beats every raw NWP model, their mean, and smart persistence on RMSE and CRPS at both lead days: yes.**
- Lead day 1: RMSE 80.6 W/m² vs 90.8 (ECMWF, best raw model), 95.2 (NWP mean), 150.0 (persistence). CRPS 37.2 W/m² vs 56.4. P10-P90 coverage 81.7 % (target 80 %).
- Lead day 2: RMSE 92.6 W/m² vs 101.3 (ECMWF, best raw model), 103.8 (NWP mean), 174.3 (persistence). CRPS 43.3 W/m² vs 64.4. P10-P90 coverage 81.7 % (target 80 %).
- **Where AURORA does not win** (subsets; report honestly, revisit with more storm data):
  - TC within 500 km, lead day 2: RMSE 116.1 vs 111.6 W/m² (Raw NWP: mean of 3, n = 234)
  - TC within 300 km, lead day 2: RMSE 118.6 vs 98.8 W/m² (Raw NWP: mean of 3, n = 71)

## Set-up

- **Issue time**: daily at 16:00 UTC (00:00 PHT) for the next 48 h. Lead day 1 = the next local day (lead 1-24 h), lead day 2 = the day after (25-48 h).
- **NWP input**: Open-Meteo previous-runs archive, ECMWF IFS 0.25°, GFS, ICON (GHI, cloud, temperature, humidity, rain, pressure, wind, gusts) and JMA (same without GHI). Lead day 1 uses the run issued about one day before the target hour (`_d1`), lead day 2 the run two days before (`_d2`). Every input was therefore available at the issue time. An operator would have a run up to a day newer, so these scores are conservative.
- **Not used**: the low/mid/high cloud split (archived only at lead day 0); ensemble spread (ECMWF ENS / GEFS) is not in `raw_small/`, so the spread between the four models is the uncertainty feature. Adding the ensemble API is a follow-up.
- **Target**: clear-sky index k = GHI / GHI_clear (Ineichen, Linke turbidity climatology, hour-mean), daylight hours (GHI_clear ≥ 50 W/m²), converted back to GHI for scoring.
- **Truth**: Open-Meteo satellite radiation (a satellite retrieval at 0.05°, 3 km from the town). It observes the clouds over the island; ERA5 models them at 0.25° and NASA POWER is a 1° product. Phase 1 showed the satellite series agrees with the Tsai et al. (2020) annual GHI within 2.6 %. None of these is a measurement; scores against ERA5 are given as a cross-check below.
- **Model**: LightGBM quantile regression, one model per lead day and quantile level (19 levels, 0.05-0.95, so CRPS can be computed), refit every month on all earlier data (expanding window, training truth ends 3 days before the test month). Crossing quantiles are sorted.
- **Calibration**: split conformal per quantile level, grouped by lead day and season, using the out-of-sample scores of the previous 365 days of the backtest. P50 is not shifted.
- **Sample**: hours where ECMWF, GFS and ICON all have GHI and persistence exists, so every forecast is scored on the same hours (n = 16078 lead-day hours).

## Limitations

- The reference is a satellite retrieval, not a pyranometer. No ground data exist for Itbayat.
- NWP archives with GHI start in Feb 2024, so the full model is trained on at most about 2.5 years; skill should grow as the archive grows.
- Lead day 1 uses runs about a day older than an operator would have, so operational skill should be a little higher; the comparison with raw NWP is fair because both use the same runs.
- Typhoon-hour statistics rest on a few storms.
- The demand model is trained on synthetic load.
